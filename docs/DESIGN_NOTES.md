# Demo v3

References reviewed: ORVA https://centrolmatrix.com/work/orva ; Animorio https://animorio.com/en/animations/hanger-button/ ; NAMESAKE https://namesak3.com/ ; Codrops https://tympanus.net/Development/3DCarousel/ ; ReadyHT https://readyht.com/templates/readyht-lineup/ ; PrintBlob https://wordpress.org/plugins/printblob/ .

Original implementation: depth showroom, glass panels, swipe/arrows/keyboard and horizontal wheel navigation; local raster image upload, draggable print overlay, scale slider, reset/remove and illustrative price. No third-party source copied. Existing rack retained.

Limitations: SVG shirts are illustrations; no physical cloth simulation, real 3D garment, production print output, checkout or backend. Uploads stay in memory and disappear on refresh. Prices are demo only. Vertical page scrolling remains available. Next: real front/back assets, text layer positioning, persistent designs and full mobile QA.
